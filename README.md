# Neon Rush - Cyberpunk Web Game

A sleek, fast-paced arcade color-matching game built with modern web technologies (**Tailwind CSS**, **HTML5 Canvas/JS ES6**, and **Web Sound Assets**). Designed for GitHub hosting via **GitHub Pages**.

## 🚀 Live Demo / GitHub Pages Setup

To publish this project live on GitHub:

1. **Upload Files**: Create a new repository on GitHub and upload all files from this directory (`index.html`, `style.css`, `game.js`, and the `assets/` folder).
2. **Enable GitHub Pages**:
   - Go to your repository **Settings** -> **Pages**.
   - Under **Source**, select `Deploy from a branch`.
   - Select `main` branch and `/ (root)` folder, then click **Save**.
3. Access your live game at `https://your-username.github.io/your-repo-name/`.

## 🎮 Game Features
- **Modern UI**: Dark glassmorphic design with Tailwind CSS and vibrant neon accents.
- **Sound Effects**: Included `.wav` audio feedback for clicks, matches, combos, errors, and game over.
- **Streak & Bonus System**: Build multipliers and earn extra time by maintaining high streaks.
- **High Score Persistence**: Saves high score locally in your browser (`localStorage`).
